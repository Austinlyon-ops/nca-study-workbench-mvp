# 个人知识库：使用与现场验收

这是独立的本地知识库，不改动现有 NCA 学习网站。运行时只需要 `index.html` 一个文件；样式、逻辑、图标、初始示例全部内置。无需安装软件、启动服务器、联网或登录。

`E:\GDRIVE\MClaudD\AI_Codex_Workspace\CodexProjects\nca-study-workbench-mvp\nca-study-desk\knowledge-base\index.html`

1. 在 Windows 文件资源管理器中进入上述文件夹。
2. 双击 `index.html`。如果默认打开方式不正确，右键 → 打开方式 → Microsoft Edge 或 Google Chrome。
3. 第一次在这个浏览器中打开，会生成 3 条可编辑、可删除的 GPU 示例。左侧选一条即可看详情。

同目录的说明与测试脚本不是运行依赖，不必打开；不用输入任何命令。建议固定使用同一个浏览器、同一用户配置和同一个文件位置，不使用隐私/无痕窗口。

## 每个功能在哪里

| 功能 | 操作入口 | 通过标准 |
| --- | --- | --- |
| 新增 | 顶部绿色“＋ 新增条目” | 填标题、标签、正文，点击“保存条目”；立即进入列表并显示详情 |
| 查看 | 左侧点击知识条目 | 右侧显示对应标题、标签、完整正文、创建和修改时间 |
| 编辑 | 选中条目后，右侧上方“编辑” | 修改后点“保存条目”；“取消编辑”不会写入修改 |
| 删除 | 选中条目后，右侧上方红色“删除” | 必须确认才删除；先试取消，条目应仍在 |
| 搜索 | 顶部“搜索标题或正文…” | 输入即筛选，不分大小写；命中黄色高亮；点 × 清空 |
| 标签 | 左侧“按标签筛选” | 点标签，只看该标签；点“全部”恢复；可与搜索同时使用 |
| 导出 | 顶部“导出备份” | 在浏览器下载列表看到 JSON；无论当前怎么筛选，均导出全部已保存知识 |
| 导入 | 顶部“导入恢复” | 选择 JSON，通过校验后出现覆盖确认；确认才恢复 |
| 安全备份 | 成功导入后，页面底部“下载覆盖前安全备份” | 下载上一次导入前的原始数据；只保留最近一份，不是长期版本历史 |

在窄屏下，条目列表在上，详情/编辑在下；点击条目、新增或编辑后会滚动到操作区。

## 建议现场按这个顺序演示

先确认自己目前的数据已备份。导入会整体替换，不是追加合并。

1. 新增一条：标题 `我的 GPU 巡检记录`；标签 `GPU, 现场演示`；正文 `今天检查 NVLink 连接状态，并记录 GPU 温度。`。
2. 搜索 `巡检`，应只出现匹配标题并高亮；再搜索正文里的 `nvlink`，同样能找到。
3. 保留搜索词，再点“现场演示”标签，验证两个条件同时有效；点“全部”并清空搜索。
4. 选中这条记录，点“编辑”，正文加上 `补充：核对驱动版本。`，保存。
5. 按 F5 刷新，重新选中条目，确认新增的文字仍在。也可关闭此浏览器窗口，再双击同一文件验证。
6. 点“导出备份”；按 Ctrl+J 查看下载列表，找到 `knowledge-base-backup-日期.json`，记住保存位置。
7. 点“删除”，先选取消，验证记录还在；再删除并确认，验证列表中消失。
8. 点“导入恢复”，选择步骤 6 的 JSON，确认覆盖恢复。
9. 重新找到该记录，确认正文、标签和时间恢复；按 F5 后仍存在。

另外可验收错误文件：用记事本创建 `错误测试.json`，仅填写 `{broken`；导入时应提示“JSON 格式错误”，现有知识应保持不变。空白标题也应被阻止保存。

## 保存与备份说明

- 主存储键：`personalKnowledgeBase_v1`。结构为 `{ "version": 1, "entries": [...] }`。
- 每条包含 `id`、`title`、`tags`、`content`、`createdAt`、`updatedAt`；时间按 ISO UTC 保存，界面按本机时间显示。
- 新增、编辑、删除、恢复都先写入 localStorage，成功后更新界面；保存失败会提示，不能当成已保存。
- 备份完整保留所有字段；搜索与标签只改变显示，不改动原始内容。
- 导入先解析并检查整份文件，再请求确认。安全备份和正式恢复任一写入失败，都不替换当前知识库。
- 安全备份键：`personalKnowledgeBase_v1_safetyBackup`。下载文件也可以通过“导入恢复”还原。如果原有存储已经损坏，安全备份保留的是损坏原始文本，以便留证，不会自动修复它。
- 数据不写回 `index.html`，也不会随 HTML 文件同步或分享。换浏览器、电脑或文件位置前，先导出 JSON，再在新位置导入。
- localStorage 不是永久保险箱：清理浏览器数据、隐私模式、浏览器策略或空间限制会影响存储。请定期把 JSON 另存到可靠位置；备份是明文文件，不宜随意分享。
- 用户主动删空后，刷新不会重新塞入示例；空知识库也能导出和导入。
- 限制：标题 300 字、正文 200000 字、最多 30 个标签且每个 50 字；最多 10000 条，导入文件不超过 10 MB。实际可保存总量还取决于浏览器配额。
- 同时打开多个窗口时，检测到库已在其他窗口变化会阻止覆盖，提示保留草稿并刷新。
