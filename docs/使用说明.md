# NCA 备考工作台 v0.1 使用说明

## 安装和打开

1. 双击 `NCA-Study-Desk-Setup-0.1.0-x64.exe`。
2. 在中文安装向导中保持“当前用户安装”，按提示完成安装。
3. 从桌面或开始菜单打开“**NCA 备考工作台**”。它会打开独立窗口，不需要启动命令或开发服务器。
4. 进入“今日学习”，选择 20、45 或 60 分钟，再按“继续学习”完成知识卡和当堂小测。

## 学习与记录

- 答错、猜对或标记“还不确定”的题目会进入“错题与复习”。
- 标记“题目有疑问”会单独保留，不能自动判定为知识薄弱。
- 关闭窗口后，下次会在本机恢复学习状态。
- “短测”只有 5 道原创题，是计时交互演示，不是官方完整模拟考试。

## 备份、恢复和卸载

1. 在“资料依据与设置”选择“导出备份”，保存 JSON 文件。
2. 恢复时选择“导入恢复”；无效文件会被拒绝，覆盖前会再次确认。
3. “重置全部记录”有两次确认；请先导出备份。
4. 可在 Windows 设置的“已安装的应用”中正常卸载。学习数据与程序目录分开，卸载默认保留学习记录；如不再需要记录，请先导出后手动删除应用用户数据目录。

## 内容边界

首版只有 AI/ML/DL、CPU/GPU、训练/推理一个学习单元、3 张知识卡和 5 道原创练习题。它是个人学习辅助工具，不是 NVIDIA 官方产品，也不声称包含或提供泄露真题。
