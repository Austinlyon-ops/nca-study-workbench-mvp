# NCA Study Hub v0.3.1 教学补充与发布说明

## 改动分类与内容

本轮属于**补充**。Day 1、Day 2 原有知识卡、材料导读、各 10 道计分选择题和 2026-10-02 课级修订记录保留；在唯一内容源中新增每课五节主课、六项理解练习、可选短诊断、虚构教学情境与转入下一课的桥接。每项短答可保存原答、修订及提示接触，参考分析默认折叠。新增练习不计入原 80 道题、FSRS 或掌握判断。

Day 1 按“输入/输出→AI/ML/DL 范围→生成与训练/推理→数据/方法/算力→综合判断”展开。Day 2 按“CPU/GPU 工作结构→硬件单元与软件→计算/容量/带宽→吞吐/延迟→训练/推理资源”展开。两课材料导读改为主课先行，知识卡供学后速查。

## 兼容与发布边界

旧 `appId=com.personal.ncastudydesk`、`NCA Study Desk` 用户数据目录和 `NCA_DESK_USER_DATA` 隔离覆盖保持不变。既有选择题、来源关系和学习记录不重写；新理解练习使用独立 ID `P-D01-*`、`P-D02-*` 与教学修订号，避免旧答与新题混同。真实学习记录没有参与迁移或验收。

公开桌面安装包默认把记录存放在用户本机；网页版保存在当前浏览器。两端共用课程内容，但学习记录不自动互通。应用内云备份是用户自行配置独立服务和口令后的可选功能，公开安装包不附私人口令。本项目不是 NVIDIA 官方产品，也不是考试 dump 或学习效果认证。

## 本地重新构建

在 Windows 10/11 x64、Node.js 20+ 中于 `nca-study-desk` 目录运行：

```powershell
npm ci
npm run build:content
npm test
npm run verify:content
npm run smoke:electron
npm run accept:v03
npm run dist
```
