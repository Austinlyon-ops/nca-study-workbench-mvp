# 内容入口

当前唯一运行内容源是 `nca-content-v0.2.json`。日常维护卡片、题目、答案、来源和考点映射只改这份文件，再运行 `npm run build:content`，由它生成桌面内容、网页内嵌内容和考点覆盖表。

`batch2-infrastructure.json`、`batch2-operations.json` 是2026-09-24第二批的冻结作者片段，仅保留加工来源；不参与运行或后续构建。合并后的题型、去重和交叉复核结果以主JSON为准，不在这些片段上继续改题。

`question-bank-review-v0.2.json` 是历史题库14题定向抽查记录，不是准入题集；它保留原题/原答案及争议处置。380条历史题未批量进入课程。

知识事实与学习状态分开：浏览器localStorage、桌面用户数据中的答题/自评才是应用记录。这里不保存用户掌握度，不导入聊天得分。原始教材保留于原来源；`tmp/sources`只是本轮读取缓存。
